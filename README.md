# Get Ripped

The yearly Get Ripped program as a home-screen web app: onboarding baseline, daily session and habit checkboxes with points, meal and reward taps with a weekly quality ratio, a daily supplement checklist, sauna and cold logging, Friday weigh-ins with a four-week rolling average, modality tests (FTP, 2K, mile) with VO2 max estimates, outcome charts, a shareable weekly card, and JSON export. A single `index.html` plus an icon and a web-app manifest. No build step. GitHub Pages publishes this repository's root.

Data lives in each phone's browser; nothing is stored on a server.
